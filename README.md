# دیدبان پتروشیمی — پنل داده

پنلی روی **tsetmc.com** و **codal.ir** که داده‌های لازم عامل «دیدبان پتروشیمی» را با یک کلیک جمع می‌کند و برای Claude آماده می‌کند: قیمت و اندیکاتورها، روند چندافقی، سطوح نمودار، جریان پول حقیقی/حقوقی، رژیم گروه ۴۴، امتیاز v2 با کالیبراسیون، و اطلاعیه‌های کدال.

اسکریپت جمع‌آوری (`src/petro_collector.js`، نسخهٔ ۲٫۱) بدون تغییر استفاده شده؛ پنل فقط روی آن سوار است.

## نصب

| روش | چه می‌گیرد | نصب |
|---|---|---|
| **Tampermonkey** (پیشنهادی) | tsetmc و کدال، هر دو از یک تب | افزونهٔ Tampermonkey یا Violentmonkey را نصب کنید و فایل [`docs/petro-watch.user.js`](docs/petro-watch.user.js) را باز کنید (Raw) تا «Install» بیاید |
| Bookmarklet | فقط دادهٔ همان سایت | از صفحهٔ GitHub Pages مخزن، دکمهٔ «دیدبان» را به نوار بوک‌مارک بکشید |
| Console | فقط دادهٔ همان سایت | محتوای [`docs/petro-watch.js`](docs/petro-watch.js) را در Console مرورگر (F12) روی tsetmc.com بچسبانید |

## روش کار

1. روی tsetmc.com دکمهٔ **دیدبان** (پایین صفحه، یا `Alt+P`) را بزنید، نماد را بنویسید و **گرفتن داده** را بزنید.
2. **کپی برای Claude** را بزنید و در گفت‌وگو بچسبانید. اگر پرامپت عامل را در Project یا System Prompt نگذاشته‌اید، گزینهٔ «با پرامپت» را روشن کنید.
3. خط JSON پایان برگه را در تب **کارنامه** ذخیره کنید و هر هفته **ارزیابی همه** را بزنید (افق ۵ روز).

پنل چه نشان می‌دهد: موقعیت (A تا D)، رژیم گروه، امتیاز بدون کدال و ناحیه، احتمال رشد ۱ تا ۱۰ روزه در برابر نرخ پایه (base rate) و لبه (edge)، امتیاز پیشنهادی کدال ۷ روز اخیر، روند روزانه/هفتگی/یک‌ساله، نردبان سطوح حمایت و مقاومت، جریان پول، گروه و شاخص، دفتر سفارش، سهامداران، IPO، بنیادی سریع و فهرست اطلاعیه‌ها با متن.

## ساختار

```
src/petro_collector.js   اسکریپت جمع‌آوری (بدون تغییر)
src/fetch-bridge.js      fetch برای اسکریپت؛ در Tampermonkey درخواست‌های بین‌سایتی را از GM_xmlhttpRequest می‌فرستد
src/panel.js, panel.css  پنل و داشبورد (Shadow DOM، راست‌به‌چپ، فونت Vazirmatn)
src/site.html            صفحهٔ نصب و نمایشگر (GitHub Pages)
prompt/                  پرامپت عامل، نسخهٔ ۲٫۱
docs/                    خروجی build: اسکریپت‌ها، صفحهٔ Pages، prompt.md، sample.json
test/                    آزمون آفلاین با دادهٔ ساختگی (Playwright)
```

## توسعه

```bash
node build.mjs            # ساخت docs/ از src/
npm test                  # build + آزمون آفلاین در Chromium بی‌سر
```

نام کاربری و مخزن در `pw.config.json` است (برای لینک‌های نصب و به‌روزرسانی خودکار). برای GitHub Pages: Settings → Pages → Branch `main`، پوشهٔ `/docs`.

## محدودیت‌ها

- tsetmc و کدال خارج از ایران معمولاً در دسترس نیستند؛ پنل در مرورگر خود شما و با اتصال شما اجرا می‌شود.
- اگر کدال خطای 429 داد، یک دقیقه بعد دوباره اجرا کنید؛ خروجی خطادار را «بدون اطلاعیه» تفسیر نکنید.
- `sample.json` دادهٔ ساختگی است (نماد «نمونه» وجود ندارد).

> این ابزار داده جمع می‌کند و برای تحلیل آموزشی/پژوهشی است؛ توصیهٔ سرمایه‌گذاری شخصی نیست و مسئولیت تصمیم با معامله‌گر است.
