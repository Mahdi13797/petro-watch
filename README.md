# دیدبان پتروشیمی — پنل داده

پنلی روی **tsetmc.com** و **codal.ir** که داده‌های لازم عامل «دیدبان پتروشیمی» را با یک کلیک جمع می‌کند و برای Claude آماده می‌کند: قیمت و اندیکاتورها، **نمودار تکنیکال** (کندل، میانگین‌ها، فیبوناچی، پیوت، ایچیموکو، Bollinger، کانال روند، الگوها و واگرایی، RSI و MACD، برنامهٔ معامله)، روند چندافقی، سطوح نمودار، جریان پول حقیقی/حقوقی، رژیم گروه خود نماد، امتیاز v2 با کالیبراسیون، و اطلاعیه‌های کدال.

**فهرست پیش‌فرض:** ۱۱ نماد گروه ۲۳ (فرآورده‌های نفتی/پالایشی): شپنا، شتران، شبندر، شبریز، شسپا، شراز، شاوان، شرانل، شنفت، شپاس، شبهرن. جدول احتمال‌ها روی گروه ۴۴ (پتروشیمی) آزموده شده؛ برای این نمادها پنل هشدار «اطمینان پایین» می‌دهد.

اسکریپت جمع‌آوری (`src/petro_collector.js`) همان نسخهٔ ۲٫۱ است با دو اصلاح (۲٫۱٫۲). ۲٫۱٫۱: MarketWatch در tsetmc دیگر فیلد `flow` را نمی‌دهد و بلوک `group` خالی می‌ماند (`n_traded = 0`)؛ حالا نبودن `flow` نماد را حذف نمی‌کند. ۲٫۱٫۲: بلوک `group` حالا گروه خود نماد (مثلاً ۲۳) و شاخص همان گروه را می‌گیرد و رژیم از آن حساب می‌شود؛ `rubric.calibration_applies_to_this_group` می‌گوید جدول کالیبراسیون برای این گروه آزموده شده یا نه. هر دو اصلاح در کد پیوست پرامپت هم اعمال شد. پنل فقط روی اسکریپت سوار است.

**نسخهٔ ۲٫۳ — جعبه‌ابزار تکنیکال و نمودار:**
- **اسکریپت:** بلوک `technical` به اسکریپت اضافه شد. شامل کندل‌های تعدیل‌شدهٔ روزانه (۳۲۰ جلسه) و هفتگی (۱۰۴ هفته)، فیبوناچی اصلاحی و گسترشی، پیوت روزانه و هفتگی، ایچیموکو، Stochastic، Bollinger، MACD، واگرایی RSI، الگوهای کندلی و الگوهای کلاسیک (سقف و کف دوقلو، سر و شانه، مثلث) با خط گردن و هدف.
- **لبهٔ آزموده:** هر سیگنال لبهٔ آزمودهٔ ۱۳ ساله‌اش را کنار خودش دارد (۱۳۹۲ تا ۱۴۰۵، گروه ۴۴).
- **نمودار در پنل:** پنل نمودار را می‌کشد (SVG، بدون کتابخانه). لایه‌ها روشن و خاموش می‌شوند، بین روزانه و هفتگی جابه‌جا می‌شود، با بردن نشانگر روی نمودار جزئیات هر کندل دیده می‌شود، و تصویر PNG را می‌شود دانلود یا برای Claude کپی کرد.
- **پرامپت ۲٫۳:** از عامل می‌خواهد در هر برگه نمودار بکشد و جدول ابزارهای تکنیکال را با اعتبار هرکدام بدهد.
- **نتیجهٔ آزمون:** هیچ ابزار کلاسیکی، فیبوناچی هم، لبهٔ پایدار بیش از ±۳ واحد درصد نداشت. سطوح فیبوناچی هم بهتر از سطوح دلخواه عمل نکردند. پس این ابزارها برای رسم، حد ضرر و هدف‌اند و جهت از امتیاز v2 و جریان پول می‌آید (بخش ۴-۱-ج پرامپت).

**نسخهٔ ۲٫۴ — آزمون بازپخش و پیش‌بینی جلسهٔ بعد:**
- **آزمون گذشته:** در پنل تاریخ را در «آزمون گذشته» بنویسید (مثلاً ۱۴۰۳/۰۷/۰۷). داده دقیقاً تا پایان همان جلسه بریده می‌شود و نتیجهٔ واقعی جلسهٔ بعد جدا و بسته نشان داده می‌شود؛ پس اول برگه را کور می‌نویسید، بعد می‌سنجید. در Console: `await petroReplay('شپنا', '1403/07/07')` و برای یک بازه `await petroReplayRange('شپنا', '1403/07/01', '1403/07/30')`.
- **جلسهٔ بعد:** بلوک `next_session` با امتیاز و جدولی که روی ۱۱ پالایشی (۱۳۹۲ تا ۱۴۰۵) برآورد شده: احتمال بالا، بی‌حرکت و پایین، احتمال صف فردا، و حرکت از آخرین قیمت امروز در برابر هزینهٔ ۱٫۲۵٪.
- **دامنهٔ نوسان واقعی هر روز** از tsetmc؛ **کدال از فهرست tsetmc** (بدون محدودیت 429).
- **نتیجهٔ آزمون:**
  - جهت جلسهٔ بعد، وقتی حرکت بی‌حرکت نبود، ۸۱ تا ۸۵٪ درست بود (خارج از نمونه، ۱۴۰۳ تا ۱۴۰۵).
  - بیشتر خطاها از حرکت کل بازار و شکستن صف بود.
  - از آخرین قیمت قابل معامله، معاملهٔ یک‌روزه در همهٔ ناحیه‌ها بعد از هزینه زیان داد.
  - جزئیات در `research/README.md` و گام ۶-ب و بخش ۷-ب پرامپت.

## نصب و اجرا

| روش | چه می‌گیرد | نصب |
|---|---|---|
| **Tampermonkey** (پیشنهادی) | tsetmc و کدال، از هر دو سایت | افزونهٔ Tampermonkey یا Violentmonkey را نصب کنید و فایل [`docs/petro-watch.user.js`](docs/petro-watch.user.js) را باز کنید (Raw) تا «Install» بیاید |
| Bookmarklet | روی codal.ir هر دو؛ روی tsetmc فقط tsetmc | از صفحهٔ GitHub Pages مخزن، دکمهٔ «دیدبان» را به نوار بوک‌مارک بکشید |
| صفحهٔ GitHub Pages | فقط tsetmc | نماد را در بخش «اجرای مستقیم» بدهید |
| Console | مثل Bookmarklet | محتوای [`docs/petro-watch.js`](docs/petro-watch.js) را در Console مرورگر (F12) روی codal.ir بچسبانید |

چرا این تفاوت: API قیمت tsetmc (`cdn.tsetmc.com`) به هر سایتی جواب می‌دهد، ولی جست‌وجوی کدال (`search.codal.ir`) فقط به خود codal.ir. Tampermonkey این محدودیت را با `GM_xmlhttpRequest` دور می‌زند.

## روش کار

1. روی codal.ir یا tsetmc.com دکمهٔ **دیدبان** (پایین صفحه، یا `Alt+P`) را بزنید، نماد را بنویسید و **گرفتن داده** را بزنید.
2. **کپی برای Claude** را بزنید و در گفت‌وگو بچسبانید. اگر پرامپت عامل را در Project یا System Prompt نگذاشته‌اید، گزینهٔ «با پرامپت» را روشن کنید.
3. خط JSON پایان برگه را در تب **کارنامه** ذخیره کنید و هر هفته **ارزیابی همه** را بزنید (افق ۵ روز).

پنل چه نشان می‌دهد: برنامهٔ ساده، نمودار تکنیکال با لایه‌ها، جدول ابزارهای تکنیکال با اعتبار ۱۳ ساله، موقعیت (A تا D)، رژیم گروه، امتیاز بدون کدال و ناحیه، احتمال رشد ۱ تا ۱۰ روزه در برابر نرخ پایه (base rate) و لبه (edge)، امتیاز پیشنهادی کدال ۷ روز اخیر، روند روزانه/هفتگی/یک‌ساله، نردبان سطوح حمایت و مقاومت، جریان پول، گروه و شاخص، دفتر سفارش، سهامداران، IPO، بنیادی سریع و فهرست اطلاعیه‌ها با متن.

## برنامهٔ روزانه (HTML)

`PetroWatch.report` در مرورگر شما (روی codal.ir یا tsetmc) برای یک فهرست نماد:
- از همهٔ نمادها داده می‌گیرد و قاعده‌های برنامهٔ ساده را اجرا می‌کند.
- برای سیگنال‌های مدل کدال را سبک چک می‌کند.
- نمادها را برای جلسهٔ بعد رتبه می‌دهد. ترتیب: اول سیگنال خرید مدل، بعد ماشه‌ای که فردا دست‌یافتنی است، بعد بازدهٔ مورد انتظار ۵ روزه از جدول کالیبراسیون.
- دادهٔ نمودار دو نماد اول را نگه می‌دارد.

خروجی فشرده و تکه‌تکه است (gzip + base64، هر تکه ۱۸۰۰ نویسه با checksum). `report/build.mjs` از روی آن یک صفحهٔ HTML می‌سازد. این صفحه جدول اجرایی، دلیل انتخاب دو نماد، نمودار تعاملی همان دو نماد و جدول ابزارهای تکنیکال را دارد.

```js
PetroWatch.report.run(['شپنا', 'شتران', 'شبندر'], { label: 'پالایشی‌ها' })   // در پس‌زمینه
PetroWatch.report.status()   // running … / done chunks=N top=…
PetroWatch.report.chunk(1)   // "1/N z <checksum> <data>"
```
```bash
node report/build.mjs --chunks chunks.txt --out report.html   # محتوای صفحهٔ Artifact
node report/build.mjs --chunks chunks.txt --out report.html --file   # فایل HTML مستقل
```
تسک زمان‌بندی‌شدهٔ روزانه همین مسیر را اجرا می‌کند.

## ساختار

```
src/petro_collector.js   اسکریپت جمع‌آوری (۲٫۴): petroSnapshot، petroReplay، petroReplayRange، petroEvaluate، codalSnapshot
src/chart.js             نمودار تکنیکال (SVG): لایه‌ها، روزانه/هفتگی، نشانگر، خروجی PNG
src/report.js            برنامهٔ روزانهٔ یک فهرست نماد در مرورگر (PetroWatch.report)
report/build.mjs         ساخت صفحهٔ HTML برنامهٔ روزانه از خروجی report.js
src/fetch-bridge.js      fetch برای اسکریپت؛ در Tampermonkey درخواست‌های بین‌سایتی را از GM_xmlhttpRequest می‌فرستد
src/panel.js, panel.css  پنل و داشبورد (Shadow DOM، راست‌به‌چپ، فونت Vazirmatn)
src/site.html            صفحهٔ نصب و نمایشگر (GitHub Pages)
prompt/                  پرامپت عامل، نسخهٔ ۲٫۴ (کد پیوست آن را build.mjs با src/petro_collector.js هم‌سان نگه می‌دارد)
research/                موتور آزمون بازپخش، تحلیل‌ها و مدل جلسهٔ بعد (در مرورگر روی tsetmc اجرا می‌شود)
docs/                    خروجی build: اسکریپت‌ها، صفحهٔ Pages، prompt.md، sample.json
test/                    آزمون آفلاین با دادهٔ ساختگی (Playwright)
```

## توسعه

```bash
node build.mjs            # ساخت docs/ از src/
npm test                  # build + آزمون آفلاین در Chromium بی‌سر
```

نام کاربری و مخزن در `pw.config.json` است (برای لینک‌های نصب و به‌روزرسانی خودکار). برای GitHub Pages: Settings → Pages → Branch `main`، پوشهٔ `/docs`.

## محدودیت‌ها

- tsetmc و کدال خارج از ایران معمولاً در دسترس نیستند؛ پنل در مرورگر خود شما و با اتصال شما اجرا می‌شود.
- اگر کدال خطای 429 داد، یک دقیقه بعد دوباره اجرا کنید؛ خروجی خطادار را «بدون اطلاعیه» تفسیر نکنید.
- `sample.json` دادهٔ ساختگی است (نماد «نمونه» وجود ندارد).

> این ابزار داده جمع می‌کند و برای تحلیل آموزشی/پژوهشی است؛ توصیهٔ سرمایه‌گذاری شخصی نیست و مسئولیت تصمیم با معامله‌گر است.
